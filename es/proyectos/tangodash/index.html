TangoDash

Decisiones de stock conectadas con los datos del ERP que el equipo ya usa.

TangoDash es un proyecto pago e independiente para un cliente: un dashboard de stock conectado con datos de Tango ERP. Reúne artículos, proveedores, ventas y existencias en un mismo flujo operativo.

TIPO DE PROYECTO · Trabajo pago para cliente   /   DATOS · Privados

El problema

Cuando el stock, las ventas y la información de proveedores se consultan en distintas pantallas, decidir qué reponer requiere trabajo manual adicional. El equipo necesitaba revisar niveles de stock y preparar el siguiente paso de compra con más claridad.

Qué permite el dashboard

El flujo combina existencias, artículos y proveedores con datos de ventas. Permite definir mínimos y objetivos de stock, calcular necesidades de reposición, preparar órdenes de compra y exportar reportes operativos a Excel o PDF.

Implementación

La aplicación usa una interfaz en Next.js y TypeScript, backend FastAPI y datos en SQL Server. El dashboard es una capa de trabajo sobre la información del ERP del cliente; no reemplaza Tango ERP.

Alcance del proyecto

Es un trabajo pago para un cliente. El código fuente y los datos del negocio son privados; por eso el material público describe el flujo sin exponer registros ni pantallas confidenciales. No publico métricas de rendimiento que no estén autorizadas.

TECNOLOGÍAS

Next.js · TypeScript · FastAPI · SQL Server · Excel · PDF
