G2 Dashboard

Una vista conectada de las tareas que forman la gestión diaria de un negocio.

G2 Dashboard es un proyecto pago independiente, distinto de TangoDash. Organiza información cotidiana en módulos de operación, finanzas y ventas para que el equipo pueda pasar de un número al contexto que lo explica.

TIPO DE PROYECTO · Trabajo pago para cliente   /   DATOS · Privados

Una visión operativa amplia

El proyecto abarca stock, ranking de proveedores, compras y remitos, flujo de caja y cheques, calendario de pagos, gastos, costo de mercadería, cobranzas y evolución de ventas. Cada área forma parte de una herramienta de gestión compartida.

Pensado para los flujos reales

La idea es facilitar la revisión conjunta de la información cotidiana: qué se compra, qué pagos se acercan, qué se cobró y cómo evolucionan las ventas. Cada módulo mantiene su contexto operativo y aporta a una visión más amplia.

Implementación

El proyecto utiliza Next.js y TypeScript en la interfaz, FastAPI en backend y SQL Server para los datos. Es una implementación independiente, con sus propios flujos; no es una versión renombrada ni una extensión de TangoDash.

Alcance del proyecto

Es un trabajo pago para un cliente; el código fuente y los datos del negocio son privados. Este resumen público se limita a las funcionalidades y no muestra registros ni resultados financieros sin autorización.

TECNOLOGÍAS

Next.js · TypeScript · FastAPI · SQL Server
