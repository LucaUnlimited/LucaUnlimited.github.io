# Luca Rivera portfolio refresh

This is a dependency-free static portfolio for GitHub Pages. `index.html` contains the English and Spanish copy, `styles.css` contains all styling, and `app.js` handles the language toggle. Resume links expect `cv-en.pdf` and `cv-es.pdf` at the site root.

To update the page, edit the matching `data-en` and `data-es` attributes together. Keep public links limited to repositories that visitors can access. G2 Dashboard is described as a private product; its source stays private.
