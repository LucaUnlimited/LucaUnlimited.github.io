TangoDash

Inventory decisions connected to the ERP data the team already uses.

TangoDash is a paid, independent client project: a stock-management dashboard built around Tango ERP data. It brings articles, suppliers, sales and current stock into one operational workflow.

PROJECT TYPE · Paid client work   /   DATA · Private

The problem to solve

When stock, sales and supplier information live across different views, deciding what to replenish takes extra manual work. The team needed a clearer way to review stock levels and prepare the next purchasing step.

What the dashboard supports

The workflow combines current stock, article and supplier information with sales data. Users can define minimum and target levels, calculate replenishment needs, prepare purchase orders and export operational reports to Excel or PDF.

Implementation

The application uses a Next.js and TypeScript interface, a FastAPI backend and SQL Server data. The dashboard is a working layer over the client’s ERP information; it does not replace Tango ERP.

Project scope

This is paid client work. The source code and business data are private, so public materials describe the workflow without exposing client records or confidential screens. No performance figures are published because they have not been cleared for public use.

TECHNOLOGY

Next.js · TypeScript · FastAPI · SQL Server · Excel · PDF
